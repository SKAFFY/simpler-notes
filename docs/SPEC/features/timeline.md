# Timeline

Визуальное отображение дат из заметок на временной шкале. Нижняя панель в workspace.

## Поведение

- Отображает даты из DateIndex как точки на шкале в пределах видимого диапазона
- Клик по точке → открыть список заметок с этой датой -> клик по элементу - открыть соответствующую заметку
- Горизонтальная прокрутка для перемещения по времени
- Масштаб: автоматический подбор интервала (годы/месяцы/дни)

## Визуал

- Горизонтальная линия с точками
- Точки кликабельны — при наведении показывается название заметки
- Если на одну дату несколько заметок — группировка

## Ограничения

- Для MVP: простая линейная шкала, без зума
- Данные: только даты, найденные парсером
