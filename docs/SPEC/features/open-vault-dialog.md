# Open Vault Dialog

Диалог выбора директории с заметками.

## Реализация

- Использует крейт `rfd` (Rust File Dialogs) для нативного диалога
- При выборе: `Vault::open(path)` → обновление AppState

## Триггеры

- Меню: Файл → Open Vault
- Первый запуск: кнопка [Open Vault] на пустом экране
- Автозагрузка: при старте приложения, если `settings.last_vault_path` существует и директория читается — `Vault::open(last_vault_path)` без показа диалога

## Процесс

1. Открывается нативный диалог выбора папки (или используется `last_vault_path` при автозагрузке)
2. Пользователь выбирает директорию
3. `Vault::open(path)` в фоновом потоке
4. UI показывает спиннер/состояние загрузки
5. После загрузки: Project Panel заполняется файлами, активна первая вкладка (если есть файлы)

## Ошибка

Если выбранная директория не существует или не читается — показать сообщение об ошибке.
