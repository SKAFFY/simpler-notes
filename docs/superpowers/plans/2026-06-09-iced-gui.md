# Iced GUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement desktop GUI using [Iced](https://github.com/iced-rs/iced) (master, 0.15.0-dev) — заменяет `simpler-notes-gui` (gpui) которая не компилится на macOS.

**Tech Stack:** Rust, Iced master (git), tokio, comrak, simpler-notes-core, rfd

**Spec:** `docs/SPEC/features/workspace-layout.md` и все зависимые `docs/SPEC/features/*.md`

---

## File Structure

```
crates/iced-gui/
├── Cargo.toml
└── src/
    ├── main.rs                 — точка входа, iced::application()
    ├── app.rs                  — App, Message, update, view
    ├── theme.rs                — кастомная тема (dark)
    ├── workspace/
    │   ├── mod.rs              — workspace layout (3-panel)
    │   ├── title_bar.rs        — строка заголовка + меню
    │   ├── project_panel.rs    — левая панель: file tree
    │   ├── editor_panel.rs     — табы + контент editor/preview
    │   └── lower_panel.rs      — нижняя панель: search, diagnostics
    └── widgets/
        ├── mod.rs
        ├── file_tree.rs        — рекурсивный file tree widget
        ├── markdown.rs         — comrak-based markdown renderer + wikilinks
        └── tab_bar.rs          — кастомный tab bar
```

## Архитектура (The Elm Architecture)

```
App
├── vault: Option<Vault>
├── tabs: Vec<TabState>
├── active_tab: Option<usize>
├── project_panel_visible: bool
├── project_panel_width: f32
├── lower_panel_visible: bool
├── lower_panel_active_tab: LowerPanelTab
└── editor_mode: EditorMode

Message
├── VaultOpened(Result<...>)
├── VaultClosed
├── FileSelected(PathBuf)
├── TabSelected(usize)
├── TabClosed(usize)
├── EditorAction(text_editor::Action)
├── ModeChanged(EditorMode)
├── SearchQueryChanged(String)
├── ToggleProjectPanel
├── ToggleLowerPanel
└── Save
```

Iced master использует `iced::application()` с `Task` для async операций (как в примере `editor`).

## Фазы реализации

### Фаза A — Базовое окно + Vault
- `main.rs`: `iced::application()` с `tokio` runtime и features: `wgpu`, `highlighter`, `tokio`, `advanced`
- `app.rs`: `App` struct, `Message` enum, `update()`, `view()`
- Открытие vault через `rfd::AsyncFileDialog` (как в примере `editor`)
- Welcome screen когда vault не открыт
- Empty editor screen когда vault открыт но нет активного таба

### Фаза B — Workspace layout + Title Bar
- 3-панельный layout: `column![title_bar, content]`
- `content = row![project_panel, editor_area]`
- Нижняя панель (optional, toggle)
- Resize handle между project panel и editor (drag через `PaneGrid` или кастомный)
- TitleBar: кастомный, без нативной строки меню macOS
- Меню: Файл (Open Vault, Close Vault, Exit), Вид (Toggle Project Panel, Toggle Lower Panel, Toggle Preview)

### Фаза C — Project Panel (File Tree)
- Кастомный file tree widget (`widgets/file_tree.rs`)
- Чтение .md файлов из vault через `vault.list_md_files()`
- Collapsible директории
- Клик по .md → `FileSelected` message → открыть в редакторе
- Diagnostics: иконка ⚠ для файлов с `vault.get_diagnostics()`

### Фаза D — Editor Panel + Tabs + Text Editor
- `TabBar` (`widgets/tab_bar.rs`): имя файла + ✕
- `text_editor::Content` для редактирования
- Синхронизация с `Vault.buffer` при смене таба
- `Cmd+S` → save в vault через `vault.write_note()`

### Фаза E — Preview + Split режим
- `widgets/markdown.rs`: comrak-based markdown renderer
- `[[wiki-link]]` → кликабельные элементы (кнопки)
- `@tags` и `!даты` → plain text (MVP)
- Split: source слева, preview справа (50/50)
- Режимы: Source → Split → Preview (циклическое переключение)

### Фаза F — Lower Panel + Search
- `workspace/lower_panel.rs` с табами: Search, Diagnostics
- Search: `TextInput` + `vault.search()` — результаты кликабельные
- Diagnostics: список из `vault.all_diagnostics()`

### Фаза G — Keyboard shortcuts + polish
- `Cmd+B` → Toggle Project Panel
- `Cmd+J` → Toggle Lower Panel
- `Cmd+F` → Open Search tab + focus
- `Cmd+Shift+S` → Toggle Preview
- Автокомплит для `@`, `[[`, `!` (post-MVP)

## Ключевые решения

| Решение | Почему |
|---------|--------|
| `iced::application()` + tokio | Используем tokio для async file I/O (как в editor примере) |
| comrak вместо `iced::widget::markdown` | Iced markdown widget не поддерживает кастомные ссылки (wikilinks) |
| Кастомный file tree (widgets/file_tree.rs) | У Iced нет встроенного tree widget |
| `text_editor::Content` | Нативный мультилайн редактор Iced с undo/redo |
| 3-панельный layout через `row!`/`column!` | Проще и предсказуемее, чем `pane_grid` для фиксированного layout |
| Темная тема через `iced::Theme::Dark` + кастомные style функции | Соответствует gpui теме |

## Зависимость от simpler-notes-core

API core используем напрямую — никаких изменений в core не требуется:

- `Vault::open(config)`, `Vault::list_md_files()`
- `Vault::read_note()`, `Vault::write_note()`
- `Vault.buffer` (`Arc<RwLock<Buffer>>`)
- `Vault::search()`, `Vault::get_diagnostics()`, `Vault::all_diagnostics()`
- `Vault::autocomplete_tags/links/dates()` — для будущего автокомплита
- `Vault::get_backlinks()`, `Vault::get_outgoing_links()` — для Graph View (P2)
- `Vault::get_dates_in_range()` — для Timeline (P2)
- `Vault::resolve_link()` — для навигации по wikilinks
