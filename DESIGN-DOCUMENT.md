**UI библиотека:** https://github.com/zed-industries/zed/tree/main/crates/gpui — напрямую + https://github.com/longbridge/gpui-component + `gpui::Editor` из Zed

## Чего хочется: 
* Нативное десктоп приложение без браузера - electron отстой
* Отдельные крейты:
    * `core` — бизнес-логика (парсер, хранилище, индексы)
    * `gui` — десктоп приложение на gpui
    * `mcp` — MCP-сервер для headless-доступа (агент)
    * (Возможно) Поддержка webView
* Синхронизация:
    * Поддержка git
    * (Возможно) selfHostServer
* Требования:
    * Md редактор
    * Ссылки на другие файлы в простой форме
    * Файлы хранятся на диске в plainText
    * Файловая структура 1-1 как в fileManager - если к заметке прикреплена картинка - кассет этой картинки хранится рядом с файлом и виден.
    * Подобие mindMap(просто красивое отображение)
    * Поддержка тегов(вместо канбанов и других систем организации - пользовательские теги: inProgress, todo, done)
    * Поддержка дат - написал дату 21.07.2003 - на таймлайне появилась точка(вместо тасок и дедлайнов)
    * Нет чата с агентом - открыл opencode и он подключился к mcp
    * Опционально(что хотелось бы видеть):
        * Картинки
        * Схемки
        * Нумерованные заголовки (простой md их не поддерживает)
        * При поиске mindMap сужается динамически
        * Добавлять в проект собственный .vault c базой знаний
* Возможные проблемы:
    * Просроченные задачи теряются — нужен QL для поиска: where tags contain @inProgress and date before now.
    (Актуальная спецификация QL: docs/SPEC/overview.md)
    * Формат дат. При смене - нужно обновить все индексы и файлы

Отличия от имеющихся приложений: 
* Никаких задач, листов, типов, проектов
* Любая задача это дата. 
    * Дата имеет: 
        * Обязательно: дату
        * Опцианально: длительность, важность(есть на таймлайне/нет на таймлайне), период - крон дата или аналог для календаря.
    * Дата отображается как строка в которой она написана
* Тег вместо типов(@project @task и тд)
