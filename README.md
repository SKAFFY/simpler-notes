# Simpler Notes

Нативное десктоп приложение для заметок на Rust (gpui).

## Суть

Плоские Markdown-файлы на диске, один к одному с файловой системой.
Никакой базы данных — заметки это просто `.md` файлы в папке (vault).
Прикреплённые файлы (картинки) хранятся рядом с заметкой и видны в файловой системе.

### Ключевые фичи

- `@теги` — пользовательская организация вместо папок/канбанов/типов
- `[[вики-ссылки]]` — связи между заметками
- `!DD.MM.YYYY` — даты, которые автоматически появляются на таймлайне
- Timeline, Graph View, QL-поиск (гибрид индекса и ripgrep)

### Чем не является

- **Не task-трекер** — нет отдельной сущности «задача». Но можно трекать
  задачи через даты: пользователь сам строит эту абстракцию через `@теги`
  и `!даты`.
- **Не Notion/Obsidian** — никаких баз данных или проприетарных форматов.
- **Не AI-чат** — агент подключается через MCP, отдельно от интерфейса.

## Архитектура

Проект разделён на три крейта:

- `simpler-notes-core` — бизнес-логика: парсер, хранилище, индексы, git, watcher
- `simpler-notes-gui` — десктоп приложение на gpui
- `simpler-notes-mcp` — MCP-сервер для headless-доступа (агент, скрипты)
